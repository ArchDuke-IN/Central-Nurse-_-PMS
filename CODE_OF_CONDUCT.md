# Code of Conduct

## Our standard

We want this project to be welcoming and constructive. Participants are
expected to:

- be respectful and patient;
- assume good faith and discuss technical ideas, not people;
- give and receive actionable feedback;
- respect different backgrounds, experience levels and viewpoints;
- focus on what is best for the project and its users.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sexualized language or imagery, doxxing, deliberate disruption, and publishing
private information without consent.

## Enforcement

Report unacceptable behavior to the project maintainers through the private
security contact described in [SECURITY.md](SECURITY.md), or through a private
message to the repository administrators. Reports will be reviewed
confidentially where possible. Maintainers may remove comments, reject
contributions, or restrict participation when necessary to protect the
community.

This code of conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

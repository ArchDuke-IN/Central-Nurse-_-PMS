# Security Policy

## Scope

This project is an educational, browser-based prototype. It is not a
certified medical device, is not intended for real patient data, and should
not be connected to clinical systems.

## Supported versions

Only the latest version on the default branch is actively maintained.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
GitHub's **Report a vulnerability** option on the repository's Security tab
when available. If private GitHub reporting is unavailable, contact the
repository maintainers privately through the GitHub organization profile.

Include:

- a concise description and impact;
- affected file, version or commit;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Please do not include patient information, credentials or other sensitive
personal data. We will acknowledge reports when practical, investigate the
issue, and coordinate disclosure and remediation with the reporter.

## Safe research

Security testing must be performed only against a local checkout or an
explicitly authorized environment. Do not probe production infrastructure,
third-party services or real clinical systems.
